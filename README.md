# 🍔 버거블록 (Burger Block)

> 초등학교 1~2학년을 위한 블록 코딩 학습 앱  
> 버거 재료를 순서대로 쌓으며 **순차적 사고**와 **코딩의 기초 개념**을 배웁니다.

---

## 소개

버거블록은 버거 만들기를 통해 어린 학생들이 코딩의 핵심 개념인 **순서(Sequence)** 와 **디버깅(Debugging)** 을 자연스럽게 익힐 수 있도록 설계된 교육용 웹 앱입니다.

코드 블록을 드래그해서 쌓고, 실행 버튼을 누르면 버거가 만들어집니다. 잘못된 순서로 쌓으면 틀렸다는 피드백을 받고, 고쳐서 다시 시도할 수 있습니다.

---

## 주요 기능

### 🌱 연습 모드
- 총 **2단계** (기본 버거 1개 + 디버그 1개)
- 교사 안내 하에 학생이 처음 코딩 개념을 체험하는 단계
- 비밀번호 없이 바로 접근 가능

### 💻 코딩 모드
- 총 **10단계**
  - **일반 6단계**: 기본 버거, 치즈버거, 불고기버거, 베이컨버거, 에그버거, 스페셜버거
  - **디버그 4단계**: 뒤집힌 버거, 순서가 꼬인 버거, 이상한 재료가 들어간 버거, 재료가 빠진 버거
- 디버그 스테이지는 잘못된 블록 배열이 미리 구성되어 있어 **학생이 오류를 찾아 수정**하는 방식
- 비밀번호: `456`
- 모든 단계 완료 시 자율 모드 잠금 해제

### 🎨 자율 모드
- 코딩 모드 완료 후 해금 (세션 스토리지 기반)
- 자유롭게 버거를 만들고 **내 버거로 저장**
- 저장된 버거는 하단 리스트에서 확인하고 **플레이백** 가능
- 로컬 스토리지에 영구 저장

## 학습 흐름

```
연습 모드 → 코딩 모드 (10단계) → 자율 모드 해금
               ↑
          디버그 스테이지에서
          오류 찾기 & 수정
```

## 게임 방법

1. **블록 팔레트**에서 재료 블록을 드래그해 **내 코드** 영역에 쌓습니다.
2. 블록끼리 가까이 가져가면 **자동으로 연결(스냅)** 됩니다.
3. **▶ 코드 실행하기** 버튼을 누르면 왼쪽 화면에서 버거가 만들어집니다.
4. 순서가 맞으면 ✅ 통과, 틀리면 ❌ 피드백과 함께 수정 기회가 주어집니다.
5. 디버그 스테이지에서는 이미 배치된 잘못된 블록을 찾아 수정하세요.
